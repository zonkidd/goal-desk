# 合并种子数据脚本计划

## 目标
将 `seed-db.mjs` 和 `seed-tauri-data.js` 合并为一个终端可执行的脚本 `scripts/seed-all.mjs`，直接操作 SQLite 数据库，覆盖各种边界条件。

## 技术方案

### 使用 `node:sqlite`（Node 22.5+ 内置）
与 `seed-db.mjs` 一致，无需安装额外依赖。

### 数据库表结构（来自 `repository.rs`）
```sql
areas:          id, title
goals:          id, area_id, title, description, status
desk_tasks:     id, title, content, status, due_at, linked_goal_id, 
                linked_goal_label, bear_note_id, system_reminder_id,
                show_in_timeline, planned_start_at
desk_task_activity_logs: id, task_id, action, note, timestamp
reminders:      id, title, due_at, done
```

### 测试数据覆盖范围

**领域（5 个）**：
- 工作、个人成长、健康、家庭、财务

**目标（12+ 个）**，各种状态：
| 状态 | 示例 |
|------|------|
| ACTIVE | 完成 Q2 项目交付、学习 Rust |
| PAUSED | 优化代码质量 |
| READY_TO_COMPLETE | 建立个人知识库 |
| COMPLETED | 已完成的旧目标 |

**任务（30+ 个）**，覆盖边界条件：
| 边界条件 | 说明 |
|----------|------|
| 空目标 | 年度储蓄目标（无任务） |
| 已完成目标 | 所有任务 DONE |
| 暂停目标 | PAUSED 状态 |
| 即将到期 | 今天截止 |
| 已过期 | 昨天截止 |
| 无截止时间 | 仅有 title |
| 仅有 plannedStartAt | 有开始时间无截止 |
| 收件箱任务 | 无关联目标 |
| 多状态混合 | TODO/IN_PROGRESS/DONE |
| show_in_timeline | 有时间属性的任务 |

**时间覆盖**：
- 过去 7 天的任务（已过期）
- 今天的任务
- 未来 7 天的任务
- 无时间属性的任务

## 脚本结构

```javascript
// 1. 清空旧数据（保留系统"未分类"区域）
// 2. 创建 5 个领域
// 3. 创建 12+ 个目标（各种状态）
// 4. 创建 30+ 个任务（各种状态和时间）
// 5. 输出统计信息
```

## 关键文件
- `scripts/seed-db.mjs` — 参考 SQLite 操作方式（node:sqlite）
- `scripts/seed-tauri-data.js` — 参考测试数据定义
- `src-tauri/src/repository.rs` — 表结构

## 执行方式
```bash
node scripts/seed-all.mjs
```

## 验证
1. 运行 `node scripts/seed-all.mjs`
2. 启动 `npm run tauri:dev`
3. 检查各视图数据：Today/Inbox/Goals/Board/Areas
