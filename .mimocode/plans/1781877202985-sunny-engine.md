# 日历看板多日任务显示

## 目标
待办事项有 `plannedStartAt` 和 `dueDate` 跨多个日期时，在日历视图的**每个涉及日期**都显示该任务。例如 06-01 至 06-05，应在 06-01/02/03/04/05 五天都出现。

## 当前数据流

```
Task → deriveTodayAgenda() → RawAgendaItem[] (每个任务仅一条，startsAt=plannedStartAt)
  → TimelineBuilder.groupByDate() → Map<dateKey, items[]> (每条仅映射到一个日期)
    → CalendarView 渲染
```

## 修改方案（2 个文件）

### 1. `src/lib/workspaceDerivation.ts` — 核心修改

在 `deriveTodayAgenda()` 中，对跨天任务（有 `dueDate` 且 `dueDate > plannedStartAt`），生成**多条** RawAgendaItem，每条对应一天：

```
对每个符合条件的任务：
  startDay = startOfDay(plannedStartAt)
  endDay = startOfDay(dueDate)
  
  if startDay == endDay:
    → 生成 1 条 item（现有行为）
  else:
    → 从 startDay 到 endDay 逐天生成
    → 每条的 startsAt 设为该天的 09:00（或保留原时间）
    → 每条的 id 改为 `${task.id}--day-${i}` 以避免 React key 冲突
    → 仅 startDay 那天不检查 showInTimeline；中间/末尾天仍需 showInTimeline=true
```

### 2. `src/components/views/CalendarView.tsx` — React key 去重

`WeekDayColumn` 中 `key={event.id}` 对展开后的多日任务会重复（`abc--day-0`, `abc--day-1` 本身就是唯一 key，但原始单日任务 id 不含后缀）。确保 key 唯一：

```tsx
// 改为：
key={`${formatDateKey(day.date)}-${event.id}`}
```

同理 `DayEventCard` 的 key 也需要相同处理。

## 不修改的文件

- `TimelineBuilder.ts` — `groupByDate()` 无需改动，它按 `startsAt` 分组，多条 item 自然落入不同日期
- `types/app.ts` — `TimelineItem` 类型无需新增字段
- `CalendarView.tsx` 的 `WeekView`/`DayView` 主体逻辑 — 查询 `timelineByDate.get(dateKey)` 不变

## 边界情况

| 场景 | 处理 |
|------|------|
| 任务只有 `plannedStartAt` 没有 `dueDate` | 单天，现有行为不变 |
| `dueDate` 等于 `plannedStartAt` | 单天，现有行为不变 |
| 任务跨 7+ 天 | 逐天生成，日历当前周只显示本周内的天 |
| `showInTimeline = false` 的跨天任务 | 起始日仍显示（isStartingToday），中间天不显示 |
| 周视图翻到下周 | todayTimeline 只包含 today 在范围内的任务，下周的跨天任务也会显示 |
