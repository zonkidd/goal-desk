## What to build

主窗口不再挂全局 TopBar。Inbox / Today / Goals / Board / 日历 / 提醒 / 回收站 / 每日复盘都一样：顶栏整条去掉，右上角「新建待办」一起走。页内大标题（「收集箱」「今日焦点」等）保留。今日焦点空状态的「新建待办」、左下角「全局速记」和 ⌥ Space 仍可用。侧栏顶部窗口拖拽区保留；若去掉 TopBar 后主内容区顶部无法拖动，只补一条不影响布局的拖拽热区，不要把 TopBar 加回来。

主题切换从顶栏挪到设置弹窗的「外观」区块，继续用已有主题状态与本地持久化。打开设置能立刻看到并切换日式原木 / 液态玻璃，切换后整窗立刻跟上，下次打开仍在。

成功保存、状态变更、速记就绪不再 toast、也不再占主栏常驻状态条。需要手感的操作只在被点的控件上给一记轻量 ✅。只有失败才出现可手动关掉的非阻断 toast。加载不弹窗。浏览器预览不再用常驻黄条占主栏。设置里导入覆盖等不可逆确认仍走已有危险操作流程，不要改成 toast。

`statusMessage` 必须能区分错误；成功路径可以继续写内部状态，但不得渲染为弹层。

侧栏保持「顶栏品牌 / 中部滚动导航 / 底部固定速记+设置」。底部栏不随菜单滚走，与滚动区之间留约 20–24px，滚动 System Integration 等卡片时不得叠到「全局速记」上。不要靠加大窗口底边距假装分开。

不改 `tauri.conf.json`、`Cargo.toml`、`vite.config.ts`。浏览器与 Tauri 壳层以浏览器为准。
