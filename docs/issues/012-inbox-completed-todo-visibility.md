# Issue 012: Inbox Completed Todo Visibility

Label: ready-for-agent

## Parent

`docs/prd/2026-06-11-inbox-completed-task-state-and-goal-linking-clarity-prd.md`

## What to build

Make `Inbox` the place where completed Todos remain visible without polluting active work. Add a dedicated `Completed` group inside `Inbox`, keep it collapsed by default, and ensure `DONE` Todos can be reviewed there while staying out of `Today`.

## Acceptance criteria

- [ ] `DONE` Todos appear in a dedicated `Completed` group inside `Inbox`.
- [ ] The `Completed` group is collapsed by default and can be expanded in place.
- [ ] `DONE` Todos remain excluded from `Today`, including the ongoing focus block.

None - can start immediately.
