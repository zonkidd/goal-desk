# 截图目录

将功能截图放入此目录，README.md 中的占位符会自动引用。

## 需要的截图

| 文件名 | 对应功能 |
|--------|----------|
| `quick-capture.png` | Quick Capture 快速捕获窗口 |
| `today-view.png` | Today View 今日焦点 |
| `goals-view.png` | Goals View 目标看板 |
| `inbox-view.png` | Inbox View 收件箱 |
| `board-view.png` | Board View 看板视图 |
| `areas-view.png` | Areas View 领域管理 |
| `calendar-reminders.png` | Calendar & Reminders 日历与提醒看板 |

## 截图建议

- 尺寸：1200-1400px 宽（README 中显示宽度约 600-700px）
- 格式：PNG（推荐）或 WebP
- 内容：展示各视图的典型使用状态，包含一些示例数据
