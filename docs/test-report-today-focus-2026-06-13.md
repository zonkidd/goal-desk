# 今日焦点测试报告

**测试日期**: 2026-06-13  
**测试目标**: 验证"今日持续推进"和"今日时间轴"的逻辑正确性  
**测试数据位置**: `src-tauri/src/lib.rs` 的 `demo_desk_tasks()`

---

## 测试数据设计

### 核心逻辑规则

**今日持续推进 (Ongoing Progress)**:
- 筛选条件: `status === 'IN_PROGRESS' && start <= today <= end`
- 自动派生，不受 `showInTimeline` 影响

**今日时间轴 (Timeline)**:
- 筛选条件: `status === 'IN_PROGRESS' && showInTimeline === true && start <= today <= end`
- 用户主动控制显示

### ✅ 场景 1: 多日任务+时间轴
```
任务: 【多日任务+时间轴】完成 Q2 产品规划文档
```

**预期结果**:
- ✅ 出现在"今日持续推进"（今天在时间范围内，状态为 IN_PROGRESS）
- ✅ 出现在"今日时间轴"（showInTimeline 已启用，显示开始时间 14:00）

### ❌ 场景 7: 已逾期任务+时间轴
```
任务: 【已逾期+时间轴】昨天应完成的 bug 修复
时间: 昨天 14:00 → 昨天 18:00
状态: IN_PROGRESS
showInTimeline: true
```
**预期结果**:
- ❌ 不出现在"今日持续推进"（结束时间是昨天，今天不在范围内）
- ❌ 不出现在"今日时间轴"（不在时间范围）

**业务意义**: 虽然状态是 IN_PROGRESS 且启用了时间轴，但任务的计划时间范围已过期，不应出现在今日焦点中。用户应该手动调整任务的时间范围或完成任务。

---

### ❌ 场景 8: 未来任务
```
任务: 【未来任务】明天开始的原型设计
时间: 明天 14:00 → 下周 18:00
状态: IN_PROGRESS
showInTimeline: true
```
**预期结果**:
- ❌ 不出现在"今日持续推进"（开始时间是明天，今天不在范围）
- ❌ 不出现在"今日时间轴"

**边界测试**: 这是一个异常场景——任务还未到开始时间就标记为 IN_PROGRESS。逻辑上应该过滤掉，不影响今日焦点。

- ❌ 不出现在"今日时间轴"（状态不是 IN_PROGRESS）

**业务意义**: TODO 状态的任务还未开始执行，不应出现在"持续推进"中。

---

### ❌ 场景 10: DONE 状态

- ❌ 不出现在"今日时间轴"

**业务意义**: 已完成的任务不应占用今日焦点的视觉空间。
