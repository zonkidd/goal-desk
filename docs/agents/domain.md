# Domain Docs

This repository uses a single-context domain layout.

## Sources

- Read `CONTEXT.md` before creating PRDs, issues, tests, or architecture reviews.
- Read `docs/adr/` before proposing architectural changes.

## Consumer Rules

- Use the domain terms from `CONTEXT.md` in issue titles, test names, public interfaces, and UI copy.
- Add new terms to `CONTEXT.md` when a new stable concept appears.
- Record durable architectural decisions in `docs/adr/`.
