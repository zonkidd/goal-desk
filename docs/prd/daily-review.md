# Daily Review PRD

## 1. 概述与目标 (Context & Goals)
**Daily Review（每日回顾）** 是一个完全独立的个人工作流辅助模块。它的核心目标是帮助用户快速、无压力地记录前一天或当天的复盘内容。
通过采用类似聊天应用（如 Gemini / 微信）的对话式输入与无限滚动时间线，极大地降低了撰写大段日记的心理门槛，使回顾变得碎片化、条理化。

### 核心目标
* **低心理门槛**：不强制要求长篇大论，以“对话式”一行行提交。
* **无缝查阅历史**：历史回顾与当前输入在同一视图下呈现，通过向上滚动无缝查阅过去。
* **独立性**：作为一个独立的思考复盘空间，不强制与具体的 Todo 或 Goal 绑定。

## 2. 核心场景与判断逻辑
* **入口**：在应用的主界面的左侧边栏（Sidebar）新增“每日回顾”导航项。
* **目标日期智能判断**：
  * 当用户进入页面时，系统优先检查**昨天**（Yesterday）是否已有回顾记录。
  * **如果昨天没有记录**：底部的输入框提示语为：“花个几分钟回顾一下**昨天**吧”。提交的内容将自动归属于“昨天”的日期。
  * **如果昨天已有记录**：底部的输入框提示语变为：“花个几分钟回顾一下**今天**吧”。提交的内容将归属于“今天”。
  * *(可选增强)*：支持在时间线顶部提供日期快速筛选器或跳转，方便用户查阅或直接补写某特定日期的回顾。

## 3. 交互与 UI 设计 (User Experience & UI)
### 3.1 无限滚动时间线 (Infinite Scroll Timeline)
* 整个主视图是一个无底洞式的“对话流”，最新的内容在最底部，历史内容在上方。
* 不同的日期之间通过明显的“日期分割线”隔开（例如：`2026年8月5日 星期三`）。
* 用户向上滚动鼠标滚轮，即可直接加载和查阅前天、大前天的历史回顾，无需额外的“历史记录”按钮或侧边抽屉。

### 3.2 对话式追加输入 (Chat-like Input)
* 页面底部固定一个类似 Gemini / 微信 的输入框。
* 用户输入一两行文字，按下 `Enter` 键（可支持 `Shift+Enter` 换行），即将该内容作为“一个回顾条目 (Item)”发送到上方列表中。
* 发送后的条目以分点/列表的块状形式堆叠，每一条都是独立的 UI 块，显得有条理。

### 3.3 极简纯文本
* 暂时不支持复杂的 Markdown 渲染（不处理标题、代码块等富文本），仅支持纯文本显示及基本的回车换行，保持视觉上的极简。

## 4. 条目管理功能 (Item Management)
* **修改与删除**：
  * 鼠标悬浮 (Hover) 在任意已提交的回顾条目上时，条目右侧出现小巧的“编辑”和“删除”图标。
  * **编辑**：点击后，该条目变成输入框状态，允许修改内容后保存。
  * **删除**：点击后直接删除该条目（可带简单防误删提示）。

## 5. 非目标 (Non-Goals)
* **不关联 Todo**：第一版不需要强制关联当天的 Todo，也不支持将某个 Todo 直接转为回顾条目。
* **不涉及多设备同步**：与现有的 Goal Desk 架构一致，基于本地 SQLite 存储。
* **不引入富文本编辑器**：不使用 ProseMirror 或 TipTap 等复杂的富文本引擎。
