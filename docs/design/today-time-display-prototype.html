今日焦点 - 时间展示设计原型

三种设计方案对比

方案 A：相对时间 + 紧急度视觉提示

推荐

展示已推进天数 + 剩余天数，通过颜色编码表达紧急度

✨ 设计亮点
  • • 🔥 红色 = 还剩 ≤2天（紧急）
  • • ⏰ 橙色 = 还剩 3-7天（需关注）
  • • ✅ 绿色 = 还剩 >7天（充裕）
  • • ∞ 灰色 = 无截止日期（持续推进）

方案 B：进度条 + 相对时间

通过进度条直观展示任务时间进度

⚠️ 权衡考虑
  • • ✅ 进度条视觉直观，一眼看出时间进度
  • • ❌ 占用更多垂直空间
  • • ❌ 无截止日期的任务无法显示进度条

方案 C：极简风格

只展示最关键的时间信息，最小化视觉干扰

💡 适用场景
  • • ✅ 视觉最简洁，适合任务数量较多的情况
  • • ❌ 丢失"已推进天数"信息
  • • ❌ 缺少进度感知

方案 A 增强版

最终推荐

悬停时显示完整时间线 + 按紧急度排序

🎯 最终推荐理由
  • • 信息完整：展示已推进 + 剩余时间
  • • 视觉直观：颜色编码快速识别紧急度
  • • 交互增强：悬停显示完整时间线（可选）
  • • 智能排序：按剩余天数升序，优先关注紧急任务
  • • 空间高效：不需要进度条，保持界面简洁

💡 提示：悬停任务卡片查看完整时间线 Tooltip（仅方案 A 增强版）
