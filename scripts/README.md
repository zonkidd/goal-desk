# 浏览器模式测试数据生成器

## 📋 概述

这个脚本会为 Goal Desk 浏览器预览模式生成完整的测试数据，包括领域、目标和待办任务，让你可以全面体验应用的各项功能。

## 🚀 使用方法

### 方法 1：通过浏览器控制台运行（推荐）

1. **启动开发服务器**
   ```bash
   npm run dev
   ```
   服务器会运行在 http://localhost:1420

2. **打开浏览器访问**
   ```
   http://localhost:1420
   ```

3. **打开开发者工具**
   - Windows/Linux: `F12` 或 `Ctrl + Shift + I`
   - macOS: `Cmd + Option + I`

4. **切换到 Console（控制台）标签**

5. **执行脚本**
   - 打开文件 `scripts/seed-browser-data.js`
   - 复制全部内容（Cmd+A / Ctrl+A，然后 Cmd+C / Ctrl+C）
   - 粘贴到控制台（Cmd+V / Ctrl+V）
   - 按 `Enter` 执行

6. **刷新页面**
   - 脚本执行后会询问是否立即刷新
   - 点击"确定"自动刷新，或手动按 `F5` / `Cmd+R`

### 方法 2：直接在控制台执行

如果你不想复制粘贴，可以在控制台直接输入：

```javascript
fetch('/scripts/seed-browser-data.js')
  .then(r => r.text())
  .then(eval)
```

## 📊 生成的数据

### 5 个领域（Areas）
- 🏢 **工作** - 职业发展和项目管理
- 📚 **个人成长** - 学习和自我提升
- 💪 **健康** - 运动和作息管理
- 👨‍👩‍👧‍👦 **家庭** - 家庭关系和活动
- 💰 **财务** - 理财和储蓄目标

### 12 个目标（Goals）

每个领域包含 2-3 个目标，状态分布：
- **ACTIVE** (活跃): 10 个
- **PAUSED** (暂停): 1 个
- **READY_TO_COMPLETE** (即将完成): 1 个

目标进度范围：15% - 90%

### 25 个待办任务（Tasks）

状态分布：
- **TODO** (待办): 16 个
- **IN_PROGRESS** (进行中): 6 个
- **DONE** (已完成): 3 个

任务特性：
- ✅ **18 个关联到 Goal**（展示目标-任务关联）
- ✅ **7 个无关联任务**（展示收件箱功能）
- ✅ **11 个时间线任务**（展示 Today 视图时间线）
- ✅ **6 个今日焦点任务**（IN_PROGRESS + plannedStartAt，展示 Focus 区域）
- ✅ **10 个带截止日期**（展示日期管理）
- ✅ **7 个带计划开始时间**（展示时间规划）
- ✅ **完整的活动日志**（展示任务历史记录）

## 🧹 清空测试数据

如果需要清空所有测试数据，在浏览器控制台执行：

```javascript
localStorage.clear()
location.reload()
```

或者只清空 Goal Desk 数据：

```javascript
localStorage.removeItem('goal-desk-browser-tasks')
localStorage.removeItem('goal-desk-browser-goals')
localStorage.removeItem('goal-desk-browser-areas')
location.reload()
```

## 🐛 如果遇到问题

### 数据没有显示

1. 检查控制台是否有错误信息
2. 确认脚本执行成功（应该有 "✨ 测试数据生成完成！" 输出）
3. 刷新页面
4. 打开浏览器开发者工具 → Application → Local Storage
5. 确认有以下三个键：
   - `goal-desk-browser-tasks`
   - `goal-desk-browser-goals`
   - `goal-desk-browser-areas`

### 页面显示异常

1. 清空 localStorage: `localStorage.clear()`
2. 刷新页面
3. 重新运行种子数据脚本
