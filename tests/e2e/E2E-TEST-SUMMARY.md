## 测试策略

### 1. TDD 原则
- 按照 TDD 原则编写测试
- 每个测试验证特定的用户流程
- 测试失败后修复选择器和断言

### 2. 选择器策略
- 使用精确的选择器避免歧义（如 `section h1` 而非 `h1`）
- 使用 `button:has-text()` 避免匹配描述文本
- 使用 `data-testid` 属性增强选择器稳定性

### 3. 适应性测试
- 测试不依赖特定数据（适应空数据状态）
- 验证 UI 结构和交互而非具体内容
- 使用灵活的断言（如验证"至少在某个视图中"）

### 4. 等待策略
- 使用 `waitForSelector` 等待关键元素
- 使用 `waitForTimeout` 处理动画和异步更新
- 使用 `isVisible().catch()` 处理可选元素

3. **浏览器模式**: 配置为非 headless 模式便于调试
